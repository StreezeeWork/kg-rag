# Установка программного обеспечения

## 1. Общие правила

На корпоративных ноутбуках можно использовать только программы из «Каталога разрешённого ПО», который ведёт ИТ-департамент совместно со службой ИБ и публикует в «Атласе». Сейчас в каталоге около 340 программ: офисные пакеты, среды разработки, графические редакторы, клиенты баз данных и утилиты. Права локального администратора сотрудникам по умолчанию не выдаются, поэтому установить программу самостоятельно в обход каталога невозможно. Каталог пересматривается раз в полгода: программы, для которых производитель перестал выпускать обновления безопасности, исключаются, а их пользователи получают уведомление за 30 дней до удаления.

## 2. Установка ПО из каталога

Чтобы установить программу из каталога, создайте заявку в «Помощнике» в категории «Программное обеспечение» → «Установка из каталога» и выберите программу из списка. Согласование руководителя не требуется: программа устанавливается удалённо в течение 4 рабочих часов, ноутбук должен быть включён и подключён к сети офиса или к VPN. Для платных программ из каталога, например профессиональных графических редакторов, заявку согласует руководитель подразделения, а лицензию закупает ИТ-департамент через «Казну»; срок исполнения такой заявки — до 5 рабочих дней.

## 3. Программа, которой нет в каталоге

Если нужной программы нет в каталоге, создайте заявку в «Помощнике» в категории «Программное обеспечение» → «Новая программа». В заявке укажите название и версию программы, сайт производителя, задачу, для которой она нужна, и тип лицензии. Порядок рассмотрения:

1. Руководитель подразделения подтверждает, что программа нужна для работы.
2. Служба ИБ проверяет программу: происхождение, лицензию, сетевую активность, хранение данных. Проверка занимает до 10 рабочих дней.
3. При положительном решении программа добавляется в каталог и становится доступна всем сотрудникам.

После отказа повторно подать заявку на ту же программу можно не ранее чем через 3 месяца или с новым обоснованием, согласованным с CISO.

## 4. Что запрещено

- устанавливать нелицензионные («взломанные») программы и генераторы ключей;
- устанавливать торрент-клиенты, сторонние VPN-сервисы и прокси;
- устанавливать средства удалённого управления (TeamViewer, AnyDesk и аналоги) — для удалённой помощи используется только инструмент ИТ-поддержки;
- запускать программы для майнинга криптовалют;
- устанавливать расширения браузера, которых нет в каталоге.

Агент инвентаризации ежедневно проверяет установленные программы. При обнаружении ПО не из каталога сотрудник получает уведомление в «Волне» и должен удалить программу в течение 3 рабочих дней, после чего она удаляется автоматически, а руководитель подразделения получает уведомление. Установка запрещённого ПО из списка выше — нарушение, о котором служба ИБ сообщает руководителю подразделения и HRBP.

## 5. Временные права администратора

Разработчикам, DevOps-инженерам и аналитикам данных права локального администратора могут быть выданы через «Ключ» на срок до 8 часов, после чего они отзываются автоматически. Все действия, выполненные с правами администратора, записываются в журнал и выборочно проверяются службой ИБ.
